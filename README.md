# Aura Dental: сайт стоматологии (демо)

Статический сайт на HTML/CSS/JS без сборки.

## Структура
- `index.html`: разметка и контент
- `style.css`: дизайн (цвета в `:root`)
- `script.js`: тема, анимации, слайдер до/после, форма

## Запуск
Открыть `index.html` в браузере.

## Деплой
GitHub Pages (Settings, Pages, branch main), Vercel или Netlify.
